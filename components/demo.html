video‑showcase

Visor de video reutilizable con marco tipo marquesina animado, efectos internos extensibles (lluvia, estallido…) y confetti independiente. Esta página es autocontenida: abrila tal cual, sin servidor ni build, para ver el componente andando. 

<script src="./video-showcase.js"></script>

<video-showcase
  video="clip.mp4"
  effect-mode="rain"
  width="480px">
</video-showcase>
01 — Video único adaptable · efecto lluvia

Con un solo video, el chassis toma la relación de aspecto real del clip apenas carga (sin deformarlo). Sin pasar frame-image, el marco usa el destello dorado que trae el componente por defecto. sound-control agrega el ícono de audio (acá a la izquierda, por sound-position="left" — el default es derecha) y confetti-button agrega el botón dorado de abajo.

02 — Ancho fijo · marco rápido antihorario · burst

width="360px" + frame-speed="140" + frame-direction="counterclockwise". En mobile el ancho igual queda acotado a 95vw, sin importar este valor.

03 — video-desktop / video-mobile · confetti con config propia

Con video-desktop y video-mobile el componente cambia de fuente al cruzar el breakpoint (achicá la ventana para verlo). Acá se usan dos clips distintos solo para probar el mecanismo — en producción el de mobile sería vertical.

Agregar un efecto nuevo, sin tocar video-showcase.js
customElements.get('video-showcase').registerEffect('miEfecto', class {
  init(engine) { this.particles = []; }       // engine: count, baseSize, baseSpeed
  update(dt, w, h) { /* mover partículas */ }
  draw(ctx, image) { /* dibujar; image puede ser null */ }
});

document.querySelector('video-showcase').effectMode = 'miEfecto';

Sin librerías externas · Shadow DOM mode: 'open' · observers, RAF y el <video> se limpian por completo en disconnectedCallback.
